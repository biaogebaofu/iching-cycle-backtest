# 快速上手：不需要懂程序

[返回项目说明](../README.md) · [English](QUICKSTART.en.md)

## 推荐：打开网页

打开[易经周期日历与回测](https://biaogebaofu.github.io/iching-cycle-backtest/)。

电脑、手机和平板都可以在浏览器中打开。无需注册、连接交易账户或安装编程工具。手机可使用浏览器提供的“添加到主屏幕”功能作为快捷入口；需要联网时仍需保持网络可用。

## 电脑离线使用

1. 打开官方 [Releases 发布页](https://github.com/biaogebaofu/iching-cycle-backtest/releases)，下载包含 `index.html` 的官方离线 ZIP。
2. **先完整解压**。不要直接在压缩包里打开网页，也不要只取出 `index.html`。
3. 在解压后的文件夹中，双击 `index.html`。如果系统询问打开方式，选择 Edge、Chrome、Firefox 或 Safari 等浏览器。
4. 保留解压文件夹内的资源文件；以后的使用只需再次打开 `index.html`。

Windows 和 macOS 都可使用。无需安装 Python、Node.js 或 Git。

## 首次查看

1. 先看方向日历的当前阶段、起止时间与下一阶段；“只多 / 只空”是规则输出，不是要求你下单。
2. 在历史图中选择日期范围。价格只到 2026-09-15，后面的区域没有真实价格。
3. “回测口径”默认选择“方向日历 · 中点切换基准”，起始日期为 2019-12-25，覆盖全部历史。再单独查看“原 Bias · 固定持有统计”，其门槛为 ±0.1。两者不能混算。
4. 填写“单边成本（bps）”后点“运行回测”：例如 5 bps = 单边 0.05%，一次完整进出按 0.10% 扣减。未完成的中点持仓只扣已发生的入场成本。默认 0 仅用于复现原毛收益统计，不含资金费或杠杆影响。
5. 留意样本数、已完成交易、未完成末段及缺口跳过数量。固定持有样本可能重叠，不代表可同时实现的账户收益。

历史结果只适合研究。未来日历是时间公式延伸，不是未来价格预测，模型有效性尚未证明。

回测不继承你选择的起始日期之前的持仓。当前数据只有收盘价，不计算盘中最大不利变动（MAE）。

## 常见情况

| 情况 | 怎么处理 |
| --- | --- |
| 离线打开后图表空白 | 确认 ZIP 已完整解压，资源文件未移动；重新用浏览器打开 `index.html`。 |
| 手机图表文字比较密 | 横屏查看，或缩小日期范围。 |
| 没有当天行情 | 当前为静态历史快照，不会自动更新。 |
| 看不懂红绿颜色 | 原 bias 图红色偏多、绿色偏空；方向日历按带状中点使用不同映射。分别阅读每个区域的说明。 |
| 想分享给别人 | 分享官方网页或仓库链接。源码与离线包的再分发需遵守[版权声明](../LICENSE)。 |
