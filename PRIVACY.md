# 隐私说明 · Privacy

## 中文

本说明针对当前导出的公开版，不代表原私有交易系统。

公开版只保留周期日历、时间信号计算、历史行情快照和回测展示。发布内容不应包含账户密码、API 密钥、服务器登录信息、私人仓位、下单控制、私人交易记录、运行日志、原截图或原仓库的 Git 历史。

页面无需登录，不要求交易所账户或 API 密钥，不连接实盘下单服务。时间规则与回测在当前浏览器中计算。离线包从本地资源读取历史快照，不自动下载新行情。

访问在线版时，网站托管服务仍可能按其自身政策处理网络请求和访问日志。将网页添加到手机主屏幕只是访问快捷方式，不代表数据保存在手机中，也不保证离线可用。

如果需要报告问题，请使用公开仓库的 Issues，并自行删除账户、密钥、仓位、地址和其他私人信息。无需提交任何密码。

## English

This notice covers the current exported public edition, not the original private trading system.

The public edition contains only the cycle calendar, time-signal calculations, a historical market-data snapshot, and backtest displays. Published material must exclude passwords, API keys, server credentials, private positions, order controls, private trading records, operational logs, original screenshots, and the original repository's Git history.

No login, exchange account, or API key is required. The application does not connect to a live order service. Time rules and backtests run in the current browser. The offline package reads its historical snapshot from local resources and does not automatically fetch new prices.

When you use the website, its hosting service may process network requests and access logs under its own policies. Adding the page to a phone's home screen creates a shortcut; it does not establish local storage or guarantee offline availability.

Use the public repository's Issues to report problems. Remove accounts, keys, positions, addresses, and other private information from your report. Never submit a password.
