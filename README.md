# 易经周期日历与回测 · I Ching Cycle Calendar & Backtest

[English](README.en.md) · [中文快速上手](docs/QUICKSTART.zh-CN.md) · [隐私说明](PRIVACY.md) · [版权与使用范围](LICENSE)

把原有易经时间周期规则整理为可在电脑、平板和手机浏览器中查看的日历、信号图与历史回测。无需编程，无需连接交易账户。模型的有效性尚未证明；时间规则产生的未来信号不是未来价格预测。

**发布准备中。** 计划网页地址：[在线使用](https://biaogebaofu.github.io/iching-cycle-backtest/)；计划仓库地址：[查看代码](https://github.com/biaogebaofu/iching-cycle-backtest)。发布完成后才可访问。

## 普通用户怎么用

- **手机、平板、电脑：** 首选在线网页，打开即可使用。
- **电脑离线：** 从官方 [Releases](https://github.com/biaogebaofu/iching-cycle-backtest/releases) 下载离线 ZIP，完整解压后，用浏览器打开 `index.html`。请保留同一文件夹中的资源文件。
- **手机快捷入口：** 可使用浏览器的“添加到主屏幕”功能；它是快捷入口，不保证离线使用。

不需要安装 Python、Node.js 或 Git，也不需要注册或提供交易所 API 密钥。具体操作见[快速上手](docs/QUICKSTART.zh-CN.md)。

## 内容与数据

- 周期方向日历：显示当前和后续阶段，以及时间规则生成的日历。
- 历史图：显示 ETH 价格和原始公式的 bias 信号；未来部分只显示规则信号。
- 两种独立的回测口径：方向日历基准回测、原始 bias 信号固定持有统计。
- 公开版只包含日历与回测，不包含实盘仓位、下单控制、私人交易记录或账户连接。

首开回测默认包含全部历史（从 2019-12-25 起），而非只展示近期区间。页面预览见[界面图片](docs/preview.png)。

行情是原项目页面的静态快照：`ETH-USDT-SWAP`，2 小时 K 线，共 29,473 根，范围为 2019-12-25 至 2026-09-15。原页面标注来源为 OKX；本次发布未对每根行情进行独立核验。数据不会自动更新，不应作为实时行情使用。时区、完整日线口径与检查范围见[数据说明](docs/DATA.md)。

## 两种回测怎么理解

| 口径 | 入场与退出 | 结果的含义 |
| --- | --- | --- |
| 方向日历 · 中点切换基准 | 红色高带中点转为空；绿色深带中点转为多。中点向上对齐到第一根开始时间不早于该中点的 2 小时 K 线，以该根收盘价入场，持有至下一相反事件对应的收盘价退出。 | 每次完成切换形成一笔历史研究交易。未完成的末段只按截止快照估值，不计入完成样本统计；区间开始前的持仓不带入。 |
| 原 Bias · 固定持有统计 | 在每根 2 小时 K 线开始时计算 bias，高于 `+0.1` 视为多，低于 `−0.1` 视为空；从该根收盘价，比较 2、6、12、24、72 或 168 小时后的收盘价。 | 衡量固定时间后的信号表现。样本可以重叠，不能将这些收益累乘成资金曲线或年化收益。 |

两套口径的“多、空”定义不同，结果应分别阅读。原始 bias 图的红色表示偏多、绿色表示偏空；方向日历中的带状中点切换规则使用另一种方向映射。

“单边成本（bps）”填写**单边手续费与滑点合计的基点数**：1 bps = 0.01%。默认 0 用于复现原毛收益统计；每笔完成交易扣除两倍单边成本，例如填 5 bps，往返合计扣除 10 bps。中点回测的未完成段只扣已发生的单边入场成本。结果不含资金费、杠杆、保证金和强平影响。缺口造成入场或退出价格无法验证时跳过对应样本，固定持有统计还会跳过含缺口的持有窗口；跳过数量应与结果一起阅读。

历史快照仅保留时间和收盘价，因此不计算盘中最大不利变动（MAE）。显示的均值、中位数和胜率是单段或单样本统计，不是账户资金曲线。

## 规则与边界

- 保留原项目的时间公式，包括原来的 23 时日界和不可达的 `j = 10` 分支，便于核对来源；这些细节不是模型有效性的证据。
- 规则日历可以向未来延伸，真实行情只到快照末日。
- 历史统计不证明未来能够盈利；这是一款研究与展示软件，不提供投资建议或自动交易功能。
- 页面以中文为主，附中英文标题和文档；界面尚未完整翻译为英文。
