## 先连接，再显示

![默认页面：仅显示用途与主动连接入口，不自动载入行情或方向](docs/images/01-start.png)

新版**不捆绑真实历史行情**。打开网页不会默认请求 OKX，也不会自动显示价格、回测结果、当前方向或五年日历。符合使用条件的用户自行阅读说明、作出地区与用途声明，再点“连接并读取公开行情”。请求成功后显示图表与模型日历；回测结果还需本人点“运行回测”，不会自动计算。

“免密”表示该公开端点在技术上不需要输入 API 密钥，不等于数据可以任意使用。连接不会登录账户、读取仓位或下单。

## 连接方式与数据寿命

- 浏览器直接向 OKX 官方域名发送只读 GET 请求；本项目不代理转发，也不接收账户凭据。
- 行情及当前计算结果只保存在页面内存中。刷新页面或清空后丢弃，不随 ZIP 或源码一起提供。
- 每次加载由用户主动发起，不持续自动刷新。数据数量、范围和截止时间以本次成功返回并在页面标注的内容为准。
- “请求历史范围”可选最近 90 天、1 年或 3 年，默认最近 1 年；这是请求目标，不保证完整返回。选择适用的官方服务区域，不能改选区域绕过限制。
- 网络、地区限制、CORS 或其他错误阻止连接时停止，不提供代理或其他规避方法。
- 页面与文档可以从解压包打开；真实行情连接仍需网络，不能把该包当作带行情的离线研究版。

![未选择地区或声明受限地区时，不开放数据连接](docs/images/02-restricted.png)

“免费”和“娱乐”不豁免适用法律或数据使用条件。连接前应自行确认使用资格。官方条款与数据限制见[使用边界](docs/RISK_NOTICE.md)，本项目没有宣称获得 OKX 数据再分发授权。

## 连接成功后可以研究什么

| 功能 | 含义 |
| --- | --- |
| 原公式信号与价格图 | 对当前会话取得的行情叠加时间公式信号。未来信号不含未来真实价格。 |
| 方向日历 · 中点切换基准 | 红高带中点对应假设反向（原空方向），绿深带中点对应假设正向（原多方向）；在向后对齐的 2H K 线收盘计算入场与退出。 |
| 原 Bias · 固定持有统计 | Bias 高于 +0.1 为假设多方向，低于 −0.1 为假设空方向，比较固定持有时间后的收盘价。 |
| 方向日历 | 连接成功后展示原时间公式计算的阶段。方向标签是娱乐研究输出，不是投资指令。 |

原时间算法保留，包括原 23 时日界和不可达的 j = 10 分支。模型有效性未经证明。两种回测分别统计，不模拟真实交易、资金费、杠杆、保证金或强平；只有收盘价时不计算盘中最大不利变动（MAE）。

成本参数仅用于假设统计，不会产生收费：5 bps 表示单边 0.05%，完成往返扣 0.10%；未完成中点段只扣已发生的假设入场成本。胜率、均值和中位数不是账户收益或未来盈利保证。固定持有样本可能重叠，不能累乘成资金曲线。

## 普通用户怎么使用

1. 打开网页，先阅读娱乐用途、地区与数据说明。
2. 仅在有使用资格时，选择“使用地区”“适用的 OKX 官方服务区域”“请求历史范围”，本人确认说明后点“连接并读取公开行情”。无须输入密码、账户或密钥。
3. 成功后查看本次数据范围，再选择图表范围、回测日期与假设成本，点“运行回测”。
4. 用完点“取消 / 清除本次数据”，或刷新页面结束当前数据会话。

电脑、手机和平板均使用浏览器。无需安装 Python、Node.js 或 Git。下载 ZIP 后应完整解压，再打开 index.html；包内界面和文档可本地阅读，获取真实行情仍需联网。手机主屏幕入口只是快捷方式，不保证离线可用。详细步骤见[中文指南](docs/QUICKSTART.zh-CN.md)和 [English guide](docs/QUICKSTART.en.md)。
